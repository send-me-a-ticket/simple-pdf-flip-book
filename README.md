# Flipbook - eBook Reader
Elegant yet simple PDF + EPUB Reader with Page turn animation in static HTML using pdf.js/ 3.4.120.
Browser-based database, offline support and text-to-speech support.

## Features:

### Reading

- PDF and EPUB in one static HTML file, nothing leaves the device
- Real page turns with 3D leaves, light sheen, page depth and drag-to-turn from the fore-edge
- Three layouts: two-page spread, single page, continuous scroll (Auto follows the window)
- Zoom to 500% with crisp re-rendered text and bitmaps, pan, pinch, and a live minimap (movable or off)
- Focus mode, fullscreen, riffle track with page peeks and chapter ticks
- Search with a results pane, bookmarks, "back to where you jumped from"
- Working EPUB links, footnote popovers, image lightbox, PDF link annotations

### Shelf

- Books kept on-device (IndexedDB) with covers, progress and last-read position
- Reopens straight to where you stopped; multi-file drop; remove with undo
- Home button returns to the shelf

### Annotate

- Select text to highlight (4 colours), add notes, copy with citation, look up a word (dictionary + Wikipedia), search the book for it, or read aloud from it
- Highlights anchored to text offsets, survive reflow and font changes
- Notes panel with Markdown/JSON export, import, and quote-card PNGs

### Listen & pace

- Read-aloud with sentence highlighting and self-turning pages, voice and speed control
- Sprint mode (one word at a time, adjustable wpm)
- Auto-turn timer, reading ruler, guided bold

### Room & type

- Seven themes plus system Auto and a custom builder; accent tints to each book's cover
- Night light, parallax tilt, optional page sounds
- Nine reading faces, size, leading, margins, alignment, publisher CSS toggle

### Insight

- Reading stats: daily goal ring, 14-day chart, streak, pace, time to finish
- Finish-the-book celebration; progress in the tab title and favicon

### Control

- Command palette (Ctrl+K) with fuzzy search over commands, chapters, shelf and page numbers
- Shortcut sheet (?), overview grid of pages or chapters, tabbed navigator (Contents · Notes · Results)
- Keyboard, mouse, wheel, touch and swipe throughout; responsive down to phone widths
